## 수정 사항

- 재생 정보 조회가 CORS·통신 오류로 실패하면 확장프로그램에서 재요청합니다. inKey 유무와 관계없이 VOD·클립에 적용됩니다.
- MP4 사전 확인의 일시적인 오류를 재시도하며, 연결 실패가 계속되면 Chrome 기본 다운로드로 전환합니다.
- 오류 메시지에 요청 단계와 서버를 표시해 원인 확인을 돕습니다.

제보자의 로그가 없어 정확한 발생 원인은 확정하지 못했으며, 재현한 실패 경로를 수정했습니다.

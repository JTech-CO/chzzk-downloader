# 안녕하세요. Chzzk Downloader 개발자입니다.

---

`2.3.2`의 주요 변경 사항을 안내드립니다.

## `2.2.6` 대비 달라진 점

- 병렬 전송의 대기를 줄이고 서버 상태에 따라 요청 수를 조절합니다.
- 작업 기록을 보존하고 직접 MP4의 조건부 이어받기를 지원하며, 실제 저장이 끝난 뒤 완료로 표시합니다.
- 첫 목록부터 빠르게 표시하고 VOD 목록·클립 카드·다운로드 탭으로 화면을 정리했습니다.
- 원본은 `src`, 직접 설치본은 `dist`, 배포 ZIP은 `releases`에 모았습니다.

## `2.3.x`에서 수정한 오류

- 정상 다운로드가 오류로 표시되던 구·신 코드 연결 문제를 보완했습니다.
- inKey VOD에서 본편을 잘못 선택해 도메인 오류가 나던 문제를 수정했습니다.
- 저장 공간을 인식하지 못해 VOD 전송을 막던 문제를 수정했습니다. 직접 MP4의 실제 임시 저장 한도 초과 시에는 기본 다운로드로 처음부터 다시 받습니다.

## 적용과 문서 관리

`dist` 갱신 후 **확장프로그램과 치지직 탭을 모두 새로고침**해 주세요.

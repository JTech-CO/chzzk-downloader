크롬 웹스토어 등록정보 — v2.3.0

<설명>
Chzzk Downloader - 네이버 치지직 VOD 및 클립 원본 화질 다운로더

치지직 채널의 VOD(다시보기)와 클립을 재인코딩 없이 MP4로 저장합니다. 동영상 또는 클립 탭에서 원하는 항목을 선택하면 사용자의 브라우저에서 다운로드합니다.

[v2.3.0 주요 기능]
- 대용량 직접 MP4: 256 MiB 이상이고 Range를 지원하는 파일을 16 MiB 구간으로 나눠 원래 바이트 위치에 기록합니다. 앞 구간이 느려도 다른 구간의 전송을 계속합니다.
- 요청 조절: 전송 엔진의 전체 동시 요청은 최대 8개이며, 서버 응답과 오류에 따라 호스트당 동시성을 조절합니다. 일시 오류 재시도와 수신 정체 제한을 적용합니다.
- 작업 복구: 다운로드 기록을 브라우저에 저장하고, 파일 식별자와 크기가 유지되는 대용량 직접 MP4는 받은 구간에서 이어받습니다. HLS/DASH의 미완성 전송은 처음부터 다시 받습니다.
- 정확한 상태: 실제 파일 저장을 확인한 뒤 완료로 표시합니다. 속도·전송량·남은 시간과 중지·재시도·파일 보기 기능을 제공합니다.
- 빠른 목록: 첫 페이지부터 표시하며 스크롤이나 전체 불러오기로 추가합니다. 불러온 목록에서 제목 검색과 최신순·과거순·인기순 정렬을 지원합니다.
- 화면 개선: VOD 세로 목록, 클립 2열 카드, 다운로드 전용 탭과 작은 창·키보드 조작을 지원합니다.

최소 Chrome 116 이상이 필요합니다. 다운로드 속도는 CDN·회선·디스크에 따라 달라집니다. fMP4 기반 HLS와 일부 DASH 구조를 지원하며, 암호화·별도 오디오 병합·다중 Period 등 지원하지 않는 형식은 오류로 안내합니다.

모든 통신은 사용자의 브라우저와 치지직 공식 API·지정 미디어 CDN 사이에서 이루어집니다. 개발자 서버를 거치지 않습니다. 작업 기록과 체크포인트는 로컬 IndexedDB에, 임시 영상 데이터는 OPFS에 저장합니다. 중지한 작업의 기록과 임시 데이터는 목록에서 지우기로 정리할 수 있으며 저장 완료된 사용자 파일은 삭제하지 않습니다.

<권한 요청 이유>

<downloads>
선택한 영상의 MP4를 저장하고 확장프로그램이 시작한 다운로드 ID의 진행·완료 상태를 확인합니다. 사용자 요청에 따라 중지·이어받기·파일 보기를 제공합니다. 관련 없는 다운로드 기록이나 기존 파일 내용은 읽지 않습니다.

<호스트 권한: chzzk.naver.com, *.naver.com, *.pstatic.net, light-slit.akamaized.net, ex-nlive-slitvod-streaming.navercdn.com>
치지직 목록·재생 정보와 미디어를 가져오는 데 필요합니다. 마지막 두 외부 CDN은 공식 API가 지정한 /chzzk/ 경로만 허용합니다. 인증이 필요한 콘텐츠는 사용자의 로그인 세션을 이용하며 개발자에게 인증 정보를 전송하지 않습니다.

<declarativeNetRequest>
확장프로그램이 시작한 Naver/Pstatic 요청에 치지직 출처의 Referer와 Origin을 설정합니다. 사용자 전체 탐색 트래픽을 수정하지 않습니다.

<offscreen>
전용 다운로드 워커를 유지하고 OPFS 파일의 Blob URL을 생성해 Chrome 저장으로 전달합니다. 영상 다운로드 이외의 용도로 사용하지 않습니다.

사용하지 않는 activeTab 권한을 제거했으며 새 권한은 추가하지 않았습니다.

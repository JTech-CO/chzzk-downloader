# 이전 버전 보존본

이 폴더는 이전 버전의 파일을 보존합니다. 현재 개발 및 배포에는 사용하지 않습니다.

| 폴더 | 내용 |
|---|---|
| `v2.2.6/`, `v2.3.0/` | 기존에 보관된 이전 버전 |
| `v2.3.2/` | 2.3.3 핫픽스 적용 전 전체 67개 파일. 복사 직후 SHA-256 일치 확인 |
| `tools/` | 과거의 단독 API 조사 스크립트 |

현재 원본은 [src](../src/), 직접 설치본은 [dist](../dist/), 스토어 등록 ZIP은 [releases](../releases/)에 있습니다.

회귀 테스트는 보존본을 읽어 이전 오류를 재현합니다. 보존본의 코드는 수정하지 않습니다.

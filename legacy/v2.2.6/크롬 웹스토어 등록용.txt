<설명>
Chzzk Downloader - 네이버 치지직 VOD 및 클립 원본 화질 다운로더

치지직 채널의 VOD(다시보기)와 클립을 최고 화질 MP4로 저장하는 확장 프로그램입니다. 동영상 또는 클립 탭에서 원하는 항목을 선택하면 사용자의 브라우저에서 바로 다운로드합니다.

[v2.2.6 주요 기능]
- 원본 화질 저장: 직접 MP4는 원본 바이트를 그대로 저장하고, DASH/HLS는 재인코딩 없이 병합합니다.
- 빠른 장시간 VOD 다운로드: 256 MiB 이상의 직접 MP4를 16 MiB 단위로 최대 8개씩 병렬 다운로드하고 OPFS에 순차 기록합니다. 일시 오류는 재시도하며 10~12시간급 영상도 길이 때문에 중단하지 않습니다.
- 재생 호환성: inKey 없는 HLS/fMP4도 초기화 세그먼트와 재생 시간·타임라인·탐색 인덱스를 보정해 macOS, Windows Media Player, 팟플레이어에서 재생과 탐색이 가능하도록 처리합니다.
- 전체 목록과 정렬: 16개/24개 이후 항목까지 불러오며 최신순, 과거순, 인기순 정렬을 지원합니다.
- 간편한 패널: 진행률, 다운로드 방식, 복사 가능한 로그를 표시합니다. 아이콘은 동영상(videos)과 클립(clips) 페이지에만 보이고 라이브(live) 페이지에서는 숨겨집니다.

개인 백업과 소장을 위한 도구이며, 모든 통신은 사용자의 브라우저와 치지직 공식 API 및 지정 미디어 CDN 사이에서 이루어집니다.

<권한 요청 이유>

<downloads>
완성된 MP4를 사용자 컴퓨터에 저장하는 데 사용합니다. 사용자가 선택한 영상만 처리하며 기존 파일이나 브라우징 기록은 읽지 않습니다.

<activeTab>
현재 치지직 URL을 확인해 동영상·클립 페이지에만 패널을 표시하고 라이브 페이지에서는 숨기는 데 사용합니다. 페이지 데이터는 수집하지 않습니다.

<호스트 권한 (chzzk.naver.com, *.naver.com, *.pstatic.net, light-slit.akamaized.net, ex-nlive-slitvod-streaming.navercdn.com)>
치지직 목록·재생 정보와 실제 미디어를 가져오는 데 필요합니다. 외부 CDN 두 곳은 치지직 공식 API가 지정한 /chzzk/ 경로만 허용하며 모든 URL을 검증합니다. 인증이 필요한 콘텐츠는 사용자의 로그인 세션을 이용하고 개발자 서버를 거치지 않습니다.

<declarativeNetRequest>
Naver/Pstatic 미디어 요청의 Referer와 Origin을 치지직 출처로 설정해 CDN의 403 오류를 방지합니다. 이 규칙은 해당 미디어 요청에만 적용됩니다.

<offscreen>
서비스 워커에서 직접 만들 수 없는 임시 다운로드 주소를 생성해 완성된 Blob 또는 OPFS 파일을 저장하는 데 사용합니다. 영상 저장 외의 페이지 접근이나 데이터 수집은 하지 않습니다.
